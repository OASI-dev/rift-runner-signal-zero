This source layout replaces the previous single-file gameplay organization.

When applying the update to an existing repository:
- Replace the old main.c with the included main.c.
- Add all included root-level .c and .h files.
- Update CMakeLists.txt so every module is compiled.
- Do not delete .git/ or repository history.
- Keep assets/, web/, .github/, and tools/.
- Delete assets/dash.wav if it remains from an earlier version; the dash mechanic and its sound are no longer used.
- If an old src/ or tests/ folder exists from an earlier version, do not use those stale C sources in the build; CMake should build the root-level modules listed in CMakeLists.txt.
