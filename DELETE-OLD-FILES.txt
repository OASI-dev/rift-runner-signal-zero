SINGLE-FILE EDITION: files that are no longer needed

The complete gameplay implementation is now in main.c. When applying this update to an existing modular repository, delete the following old source/header files after copying the new main.c and CMakeLists.txt:

Old .c files (do not delete main.c):
audio.c, background.c, bullets.c, colors.c, effects.c, enemies.c, game.c, helpers.c, leaderboard.c, pickups.c, player.c, ui.c, world.c

Old custom .h files:
audio.h, background.h, bullets.h, colors.h, effects.h, enemy.h, game.h, pickups.h, player.h

Keep: .git/, main.c, CMakeLists.txt, assets/, web/, tools/, .github/, LICENSE, README.md and other documentation. Remove obsolete dash or ambience audio assets if they exist; v0.26.0 uses only shot.wav, impact.wav, pickup.wav, enemy_down.wav and surge.wav.
