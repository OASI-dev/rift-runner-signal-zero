RIFT RUNNER: SIGNAL ZERO — v0.24.0 cleanup update

To update your existing GitHub repository without losing its history:
1. Extract this update ZIP.
2. Open project-files and copy its contents into your existing local repository root, replacing matching files. Do not delete your .git folder.
3. Keep assets/, web/, .github/, and tools/. Merge the folders; do not paste the project-files folder itself as a new nested directory.
4. Commit with summary: Clean up HUD counters and keep banana-only pickup
5. Push origin.
6. Check the latest Build and publish browser game run in GitHub Actions. The Native build check is separate from the browser deployment.

Start reading at main.c. It contains the commented main process and is 133 lines long. Detailed systems live in plainly named files such as player.c, enemies.c, background.c, colors.c, audio.c, leaderboard.c, and ui.c.

This update removes combo tracking/bonuses, kill counters, floating +points popups, health-kit/repair pickups, and data-chip pickups. The banana is the only pickup: it restores up to 18 health and grants a 5-second shield. Defeated enemies award a fixed 200 score. The previous alien designs and five procedural space environments remain unchanged.

The C syntax checks use test-only API stubs; they do not replace the real GitHub build or a live gameplay test.
