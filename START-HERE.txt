RIFT RUNNER: SIGNAL ZERO — teacher-friendly edition

The entire game is in main.c. CMake builds this file with the raylib library.

The images are in assets/images/. Keep these six files:
  player.png, red_enemy.png, blue_enemy.png, bullet.png, banana.png, bg_cradle.png

The game uses one permanent background: bg_cradle.png. The four unused background images have been removed.

There are three difficulty modes: EASY, MEDIUM, and HARD. The game includes movement, automatic shooting, enemies, banana health/shield pickup, sound effects, pause, game-over, and saved personal bests.

To build, follow BUILDING.md. The first CMake configure downloads raylib 6.0, so an internet connection is required.

Before submitting, build and run the game on the computer you will use for your university presentation.
