RIFT RUNNER: SIGNAL ZERO — v0.26.0 SINGLE-FILE EDITION

The game code is combined into ONE C source file: main.c. The other .c and custom .h module files have been removed from this edition. The game still uses raylib, CMake, the assets/ directory, browser support files in web/, and GitHub Actions workflows.

For a fresh installation, extract the single-file source ZIP into a new folder. For an existing GitHub repository, copy the package files into the repo, replace matching files, and DELETE the old gameplay module .c and .h files listed in DELETE-OLD-FILES.txt. Keep .git/, assets/, web/, tools/, and .github/. Do not delete the five current WAV files.

The game keeps the v0.26.0 difficulty rebalance, banana pickup (+up to 20 health and an 8-second shield), five original one-shot sound effects, no music or ambience, and RRNormalizeVector2 naming fix.

After updating, review the file deletions/additions in GitHub Desktop, commit, push to main, check Native build check and Build and publish browser game under GitHub Actions, and test the published game. A package check is not the same as a confirmed native/browser build or play-test.
